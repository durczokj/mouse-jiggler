# mouse-jiggler

A lightweight mouse jiggler for macOS that prevents sleep by moving the cursor 1 pixel when idle.

## Installation

```bash
brew tap durczokj/mouse-jiggler
brew install mouse-jiggler
```

## Usage

```bash
mouse-jiggler
```

Press `Ctrl+C` to stop.

## Requirements

- macOS
- `cliclick` (auto-installed with Homebrew)
